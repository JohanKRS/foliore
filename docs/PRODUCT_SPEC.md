# Product Spec

Foliore is a local-first personal EPUB library. It helps users curate a visual shelf of books, correct metadata and covers, and prepare clean EPUB copies for external readers.

The app is not an ebook reader. Original EPUB files are preserved untouched. Derived artifacts such as thumbnails, metadata JSON, technical JSON, and future `prepared.epub` files live beside each imported book in app storage.

The first delivery focuses on the Android foundation: import, parse, store, and display EPUBs.
