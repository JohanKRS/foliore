# Metadata series regression fixtures

Bibliographic fields captured from Open Library on 2026-09-11. Work JSON and the first 50 entries of each work’s `/editions.json?limit=50` response, reduced to key, title, subtitle, series, subjects, languages and work references. No book contents or descriptions are included. The 2061 search fixture is a public search response containing only requested bibliographic fields.

Sources and test results: `docs/audits/2026-09-11/metadata-series/README.md`.
